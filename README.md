## 本仓库内容

本仓库提供 EGO 数据集的**统计与质检工具**，便于数据团队在采购前快速评估数据目录的完整性。

### `stats.py`

扫描数据集目录，汇总各场景/会话的统计信息（时长、文件数、格式），输出一份可读的数据资产报告。

```bash
python stats.py /path/to/your/ego_dataset
```

示例输出：

```
场景        会话数     视频文件   标注文件   时长(约)
工厂        128        768        128        1,200h
酒店        96         576        96         900h
...
```

## 技术规格

- **目数**：2 / 4 / 6 目（主视角 + 旁视角 + 环境视角）
- **分辨率**：主视角 2160×2160@60Hz，旁/环境视角 1920×1080@30Hz
- **同步**：硬件级微秒时间同步
- **标准化**：Pre-Token 标准化格式，可直接对接 LeRobot / HDF5 / MCAP
- **标注**：手部关键点、6D 物体位姿、任务分段

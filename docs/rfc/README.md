# 公开征集 · 统一具身训练数据采集标准
## Call for Input: A Unified Egocentric Data Specification for Embodied AI

**我们正在制定一套统一的具身训练数据采集标准（EGO-S2 Data Contract），现向全球公开征集需求与意见。**

### 为什么 / Why
传统上各家各自采集、参数不统一，导致同类场景被反复重复采集——无论对人还是对资金，都是巨大的浪费。我们希望做到：**采集一次，就把大家需要的数据尽量采全**，避免重复采集。

### 我们发布了什么 / What we published
一份开放的数据需求征集表 **RFC 0.1**，提供**中英文两个版本**，覆盖 **9 大类、54 项、249 个选项**，涵盖：
- 视场角（FOV）、帧率、分辨率、快门类型
- 内外参标定、双目同步精度
- IMU 规格、是否需要深度 / 多模态（语音、眼动等）
- 数据分层（L1/L2/L3）、用途与交付形态

> 注意：这不是一份规格书，也不是合同，而是一份**公开征求意见的草案（DRAFT，open for comment）**。文中标注了「baseline 基线建议」「caveat 技术风险」和「Hard gate 硬门槛」，供讨论。

### 如何参与 / How to contribute
1. 下载下方表格，勾选你的需求（可选择**中文版**或**英文版**）；
2. 通过 **GitHub Issue / Pull Request** 反馈你的意见；
3. 或把填写结果直接发到邮箱：**2437632665@qq.com**

### 参与的价值 / Why participate
- 贡献多、参与深的同行，将**受邀参与我们的采集标准制定**；
- 未来可以**更优惠的价格、更快捷的方式**获取我们采集的数据。

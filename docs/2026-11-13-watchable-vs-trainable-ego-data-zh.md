# 数百万小时里能训练的没多少：「可看」与「可训练」的鸿沟

具身智能的数据竞赛，正在被一个容易误导的单位主导——「小时」。近一年来，多家头部厂商公开提出「一年采集数百万小时、两年冲击千万小时」真实场景视频的目标。但小时数本身不说明任何问题：一段能播放的画面，和一段能喂给模型训练的样本之间，隔着一条鸿沟。

这条鸿沟可以一句话说清——「能看」只要求视频能解码、能回放、能人工浏览；「能训练」要求它带着逐台标定的内外参、微秒级的时间同步、近乎无损的编码、逐帧元数据、质量检验门槛，以及 2D/3D 手部与动作标签，全部到位。前者一张摄像头、一张存储卡就能办到；后者需要从采集硬件到清洗标注的一整条生产链。

为了把这条鸿沟讲清楚，我们提出四档分级：可看集（L0）、素材集（L1）、训练集（L2）、评测集（L3）。

- **可看集**：双路视频能正常解码回放即可，几何标定、曝光同步、IMU 与元数据都可以放宽。只能用于场景盘点、演示、粗筛，不能用于任何训练或评测。
- **素材集**：双路视频加逐台内外参、时标、IMU 与原始归档包齐全，同步达到基本门槛，但还没做系统质检与标签。可以后期再加工、升档为训练集，不能直接训练。
- **训练集**：同步、逐台标定、近无损码率、逐帧元数据、质检门槛、2D/3D 手部与动作标签全部到位，才够得上具身模型的预训练、中训练与后训练。
- **评测集**：在训练集之上再增加度量深度真值、置信度 mask、可复跑评测脚本与固定划分，且必须与训练集物理隔离。

四档之间的差距是用硬指标划出来的。以同步为例：可看集不设要求，素材集要求双目曝光同步误差 σ<1ms，训练集要求 σ<100µs 并给出直方图、理想值 <10µs。以内外参为例：可看集不标定，训练集要求逐台标定 K/D/R/t/b、相机–IMU 外参与固定时偏，重投影 RMS<0.5px。以编码为例：可看集 8Mbps/路即可，训练集要 20–40Mbps 近无损。

结论是：在「海量」的表述下，真正达到训练集门槛的小时数，可能只是总量的一个零头。嘉穑数据（JUST DATA）以 16 万+小时已标注多目 Ego 视频为起点，坚持用微秒级时间同步、Pre-Token 标准化与自研标注算法（支持私有化部署），把每一小时都做到「可训练」而非「可看」。行业真正该竞争的，从来不是小时数，而是「可训练小时数」——一个应当被公开、被审计、被标准的指标。

# 四档分级：从「可看」到「可评测」，Ego 数据的升档逻辑

在具身智能数据采集中，最容易被误解的一个词是"时长"。16 万+ 小时的真实世界双目 Ego 数据听起来很可观，但如果不区分这些数据各自处在哪个档位，时长几乎不说明任何问题——因为一段视频"能看"和"能训练"之间，隔着标定、同步、码率、质检、标签、评测协议六道门槛。

我们把 Ego 数据分成四档，后一档包含前一档的全部要求。

**可看集（L0）**：双路视频能正常解码回放、可人工浏览即可。几何标定、曝光同步、IMU 与元数据均可放宽。用途是场景盘点、演示、粗筛和素材初选——它回答的是"我们到底拍到了什么"。但它不能用于任何训练或评测。

**素材集（L1）**：在可看之上，补齐逐台内外参、时标、IMU 与原始归档包，同步达到基本门槛（σ < 1 ms）。它没做系统质检与标签，所以仍不能直接训练；它的价值在于"可再加工"——是训练集的半成品，可离线挑选、后续升级。

**训练集（L2）**：这是第一道真正的硬门槛。同步、逐台标定、近无损码率、逐帧元数据、质检门槛、2D/3D 手部与动作标签必须全部到位。以同步为例：可看集对双目曝光同步 σ 无要求，素材集放宽到 σ < 1 ms，训练集要求 σ < 100 µs 并附直方图，理想 < 10 µs；快门从"不限"收紧到全局快门 GS，单路码率从 8 Mbps 抬到 20~40 Mbps 近无损；标定从"记录标称值"升级为逐台 K/D/R/t/b，再加相机–IMU 外参与固定时偏 td。只有越过这些，数据才具备用于预训练、中训练、后训练的资格。

**评测集（L3）**：在训练集之上，增加度量深度真值、置信度 mask、可复跑评测脚本、固定划分与下游实测举证。它回答的是"模型到底行不行"，因此必须与训练集在设备、场景、存储上物理隔离，不得混用或互相补数据。

**升档逻辑**：升档不是"加个标签"，而是按更高一列整体执行——设备、标定、同步、编码、质检、标签同步升级。51 项要求分两大块：内外参与原始采集（38 项）、清洗与标注（13 项），两块各自独立成立，可分别排期与验收。

这也解释了为什么"时长"不能直接换算成"训练数据"：同样的拍摄时长，落在 L0 和落在 L2，价值量级完全不同。四档分级的现实意义，是把"我有很多视频"和"我有可训练数据"彻底区分开，让采集、清洗、标注、评测每个环节都有明确、可量化的技术口径可依。
